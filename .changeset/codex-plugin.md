The skill set now also ships as a native Codex plugin. Codex ≥ 0.147 accepts `skills` as an array of paths, so `.codex-plugin/plugin.json` lists exactly the three promoted buckets — install with `codex plugin marketplace add witify/skills` then `codex plugin add witify-skills@witify`. The release flow keeps its version in sync alongside the Claude manifest.
